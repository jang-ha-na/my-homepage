Firebase 게시판

개발 기간 : 2026.07

개발 인원 : 1명

담당 역할 : 게시판 설계 및 Firebase 연동

프로젝트 소개

Firebase Firestore를 이용하여 게시글 작성, 수정, 삭제가 가능한 게시판을 구현했습니다.

사용 기술

HTML5 CSS3 JavaScript Firebase Firestore

구현 기능

  • 게시글 작성
  • 게시글 수정
  • 게시글 삭제
  • 게시글 목록 조회
  • Firebase Firestore 연동

프로젝트를 통해 배운 점

Firestore를 이용한 CRUD 기능과 데이터 관리 방법을 익혔으며, 비동기(JavaScript async/await)를 활용한 웹 개발 경험을 쌓았습니다.
